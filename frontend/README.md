# Faculty Finder – Frontend (Zero-Build UI)

A modern, responsive frontend for **Faculty Finder**, built using **pure HTML, CSS, and Vanilla JavaScript**.  
No NPM, no bundler, no build step — just open and run.

This UI connects to the **semantic faculty search backend** and displays ranked results with relevance badges.

---

## ✨ UI Highlights

- 🎯 Semantic search interface  
- ⭐ “Most Relevant” badge based on rerank score  
- 🌗 Light / Dark mode toggle  
- ⚡ Smooth UI transitions  
- 📱 Fully responsive layout  
- 🧠 Cross-encoder relevance awareness  
- ⏳ Skeleton loading states  
- 🚫 Graceful “No results” handling
